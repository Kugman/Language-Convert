# Language-Convert
a chrome extemnsion that converts the keyboard lwyout from English to Hebrew and vice verca, without translating the text. This extension helps users to repair the text evemthough it wroten on the wrong keyboard layout.

## Installation

1. Clone or download this repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** (top right corner).
4. Click **Load unpacked** and select the folder containing the extension files.

## Usage

- Once installed, type in any input field and by selecting the text + write click you will see the Languuage convert option on the menu. click on the write language and the exyension will automatically convert your keystrokes.
- You can add a new layout by clicking the extension icon in the Chrome toolbar and follow the instructions.
